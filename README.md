# Rosler Ceiling Fan (Bond Bridge)

로슬러 실링팬을 Bond Bridge를 통해 Home Assistant에서 제어하는 커스텀 통합입니다.
A Home Assistant custom integration that controls Rosler ceiling fans (JH-RM remotes, 447 MHz) through a Bond Bridge.

> **실험적입니다.** 프로토콜은 팬 1대와 리모컨 1개(JH-RM2)를 측정해 알아낸 것입니다. 다른 개체에서 같은지는 확인되지 않았습니다. 설정 과정에서 리모컨이 알려진 방식과 다르면 설치를 멈추고 이유를 알려 줍니다.

## 왜 필요한가

Bond 앱의 리모컨 학습으로는 이 팬이 동작하지 않습니다.

- **주파수:** 리모컨은 약 447.885MHz로 송신합니다. 흔히 알려진 447.75MHz는 Bond 수신 범위의 끝이라 학습이 불안정합니다.
- **카운터:** 신호 안에 누를 때마다 올라가는 3비트 카운터가 있고, 팬은 직전에 받아들인 카운터와 같은 신호를 무시합니다. Bond 앱은 녹화한 신호를 그대로 재생하므로 무시당합니다.

이 통합은 Bond Bridge를 송신기로만 쓰고, 명령마다 카운터를 바꿔 신호를 직접 만들어 보냅니다. 공식 Bond 통합은 필요하지 않습니다.

## 필요한 것

- Bond Bridge (BD-1000, 펌웨어 v4.40.1에서 확인)와 그 로컬 토큰
- Home Assistant 2026.2 이상
- 로슬러 실링팬과 리모컨 (JH52-1 팬, JH-RM2 리모컨에서 확인. 인증 기록상 JH-RM1, JH-RM3은 같은 계열이지만 확인하지 않았습니다)

## 설치

**HACS:** HACS > 오른쪽 위 메뉴 > Custom repositories에 이 저장소 주소를 넣고 종류를 Integration으로 선택한 뒤 설치합니다.

**수동:** `custom_components/rosler_fan` 폴더를 Home Assistant의 `config/custom_components/` 아래에 복사합니다.

어느 쪽이든 Home Assistant를 재시작합니다.

## 설정

설정 > 기기 및 서비스 > 통합구성요소 추가에서 **Rosler Ceiling Fan**을 찾습니다.

1. **Bond Bridge 연결:** 브리지의 IP와 로컬 토큰을 넣습니다. 토큰은 Bond 앱 > 브리지 > Advanced Settings > Local Token에 있습니다. 브리지 IP는 공유기에서 고정해 두세요.
2. **리모컨 학습:** 리모컨을 브리지에서 30cm쯤 두고, 안내에 따라 회전종료 버튼을 두 번(화면마다 한 번씩) 누릅니다. 통합이 두 신호에서 리모컨 ID와 체크섬 상수를 읽고, 카운터와 체크섬이 알려진 방식대로인지 확인합니다.
3. **이름:** 팬 이름을 정하면 장치가 만들어집니다.

리모컨 ID와 체크섬 상수를 이미 알고 있다면 학습 대신 직접 입력할 수도 있습니다. 팬이 여러 대면 통합을 팬마다 한 번씩 추가합니다.

브리지의 IP나 토큰이 바뀌면 통합의 **재구성**에서 고칩니다. 송신 주파수와 반복 횟수는 **구성**에서 바꿀 수 있습니다.

## 만들어지는 것

팬 한 대가 장치 하나로 등록됩니다.

| 엔티티 | 기능 |
| --- | --- |
| 팬 | 켜기, 끄기(회전종료), 속도 6단, 정방향·역방향, 자연풍 프리셋 |
| 전체종료 버튼 | 리모컨의 전체종료 |
| 타이머 버튼 3개 | 1시간, 2시간, 4시간 |
| 조명 켜기/끄기 버튼 | 리모컨의 LED 버튼. 기본으로 꺼져 있으니 조명이 있는 팬에서만 켜세요 |

## 알아둘 점

- **상태는 추정값입니다.** 팬은 자기 상태를 알려 주지 않습니다. Home Assistant는 마지막으로 보낸 명령을 현재 상태로 보여 주고, 리모컨으로 바꾼 것은 알지 못합니다.
- **리모컨을 쓴 직후 명령이 한 번 무시될 수 있습니다.** 리모컨이 남긴 카운터와 통합의 다음 카운터가 우연히 같을 때이고, 확률은 약 1/8입니다. 한 번 더 보내면 됩니다.
- **리모컨 ID는 비밀번호처럼 다루세요.** ID를 아는 사람은 전파가 닿는 거리에서 팬을 조작할 수 있습니다. 이슈나 글에 올리지 마세요. 진단 정보에서는 ID, 토큰, 브리지 주소가 가려집니다.
- **타이머 버튼은 상태에 반영되지 않습니다.** 타이머로 팬이 꺼져도 Home Assistant는 켜져 있다고 표시합니다.

| 자연풍 버튼이 켜고 끄는 토글인지, 팬이 꺼진 상태에서 방향 버튼이 듣는지 | 미확인 |
| 조명 버튼 | 미확인 (조명 없는 팬에서 개발) |

## 지원되지 않는 리모컨이라고 나올 때

설정 화면에 표시되는 두 신호의 값(버튼, 플래그, 카운터, 체크섬)을 이슈로 알려 주세요. 리모컨 ID는 포함되어 있지 않습니다. 팬과 리모컨의 모델명, 인증번호(R-R-...)도 함께 적어 주시면 도움이 됩니다.

## 프로토콜

한 번 누르면 33비트 프레임을 7번 보냅니다. 변조는 OOK, 비트 길이는 1ms입니다(0은 250µs 켬 + 750µs 끔, 1은 750µs 켬 + 250µs 끔).

```
[리모컨 ID 20비트][버튼 4비트][플래그 1비트][카운터 3비트][체크섬 4비트][0]

체크섬 = 버튼 XOR (플래그·카운터 4비트) XOR 상수      (측정한 리모컨에서 상수는 8)
```

| 버튼 | 값 (16진) | 플래그 | | 버튼 | 값 (16진) | 플래그 |
| --- | --- | --- | --- | --- | --- | --- |
| 1단 | 8 | 0 | | LED | 4 | 0 |
| 2단 | 9 | 0 | | 정방향 | 2 | 0 |
| 3단 | E | 0 | | 자연풍 | A | 1 |
| 4단 | 5 | 0 | | 역방향 | 8 | 1 |
| 5단 | 7 | 1 | | 1H | 1 | 0 |
| 6단 | 6 | 0 | | 2H | 4 | 1 |
| 전체종료 | 3 | 0 | | 4H | C | 1 |
| 회전종료 | B | 0 | | | | |

통합은 카운터를 0, 1, 2, 3, 4, 5, 7 순서로 돌려 씁니다. 6을 건너뛰는 이유는 Bond 앱과 같이 쓰는 경우 때문입니다. Bond에 카운터 2와 6의 두 묶음을 한 명령으로 저장해 두는 방법이 있는데, 그 명령이 끝나면 팬의 직전 카운터가 6이 됩니다. 통합이 6을 쓰지 않으면 둘이 충돌하지 않습니다.

## 개발

```
pip install -r requirements_test.txt
pytest
```

`scripts/e2e/run_e2e.py`는 실제 Home Assistant를 띄우고 가짜 Bond Bridge를 상대로 설정부터 송신까지 실행합니다.
